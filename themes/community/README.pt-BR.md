# Temas da comunidade

[English](README.md) · **Português**

Temas mandados por quem usa o larperCord. Cada `.kdl` daqui aparece na
[galeria da comunidade](https://rshacudevidro.github.io/larperCord/pt/community-themes.html) com prévia ao vivo,
um link que abre no criador de temas e o arquivo para baixar.

Para mandar o seu, coloque `seu-tema.kdl` nesta pasta e abra um pull request. O nó `theme` precisa de um nome, `author=`,
uma descrição (`description-en=` e/ou `description=`) e `license=`. Os passos e tudo o que é conferido estão em
[Compartilhar seu tema](../README.pt-BR.md#compartilhar-seu-tema). Só arquivos `.kdl` entram aqui.

Confira antes de mandar:

```bash
python3 tools/gen_site.py --check-community
```

No Windows:

```powershell
py tools/gen_site.py --check-community
```
