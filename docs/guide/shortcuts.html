#Mouse and other keys

  • Push to talk: the key or mouse button you pick in Settings → Voice. It only works while the window is focused.
  • Right-click works on messages, users, channels and servers.
  • Esc closes whatever is on top: a menu, the image viewer, the palette, settings.
  • Zoom: Ctrl with the =/+ key or the keypad +, - and 0. It goes from 75% to 200% and is saved.
  • Plugins can add their own shortcuts with larper.keybind; each plugin's card in Settings → Plugins lists them. The app's own shortcuts don't use the Windows (Super) key, so it's free for them.
  • If a shortcut does nothing, your desktop or window manager may be catching it first.

#Command line

bash
larpercord [options]
OptionWhat it does
--theme NAMEstarts with this theme
--list-themeslists the built-in themes and exits
--mode MODEclaro (or light) or escuro, ignoring your settings
--lang LANGpt or en, ignoring your settings
--demouses the demo data even with a token
--loginshows the sign-in screen, ignoring the saved token
--settingsopens straight into settings
--no-liveturns off the demo mode's automatic messages
--shot FILE.pngsaves a screenshot once the screen settles, then exits
--statsshows the time to first frame
--qaruns the automatic UI test, with screenshots in qa-out/
--voice-test GUILD CHANNELjoins a voice channel for 25 s, always muted (needs LARPER_TOKEN)
--helpshows the usage text

#Environment variables

VariableWhat it does
LARPER_TOKENthe account token (see Connect your account)
LARPER_RENDERERpicks the SDL render backend: opengl, vulkan, gpu or software
LARPER_HIDDENopens with a hidden window. The app draws nothing while hidden, so memory reads much lower than with a real window
LARPER_BENCHredraws nonstop, to measure the cost of a frame
LARPER_VOICE_DEBUGprints what happens in a call (opcodes, close codes, DAVE). It never prints tokens or keys
LARPER_DEBUG_MEDIAlogs why an image failed to load
LARPER_NO_FFMPEGpretends FFmpeg isn't installed
LARPER_EGL_ALLturns off the trick that skips unneeded EGL drivers
LARPER_SCENEsets up a scene for documentation screenshots
LARPER_RECORD, LARPER_RECORD_FRAMESrecords the sign-in screen as frames in a folder
LARPER_FLOODsends N presence changes per second in demo mode (load test)

XDG_CONFIG_HOME and XDG_CACHE_HOME are respected, and they're handy for running with a clean configuration.
