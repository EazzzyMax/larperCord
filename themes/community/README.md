# Community themes

**English** · [Português](README.pt-BR.md)

Themes sent in by people who use larperCord. Every `.kdl` here shows up in the
[community gallery](https://rshacudevidro.github.io/larperCord/community-themes.html) with a live preview,
a link that opens it in the theme builder and the file to download.

To add yours, put `your-theme.kdl` in this folder and open a pull request. The `theme` node needs a name, `author=`,
a description (`description-en=` and/or `description=`) and `license=`. The steps and everything that is checked are in
[Sharing your theme](../README.md#sharing-your-theme). Only `.kdl` files go here.

Check it before sending:

```bash
python3 tools/gen_site.py --check-community
```
